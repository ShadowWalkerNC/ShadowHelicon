# Experiment lifecycle
IDEA → EXPERIMENT → VALIDATED → CANDIDATE → APPROVAL → ADOPTED, or REJECTED.

Execution status is separate: NOT RUN, PASS, FAIL, BLOCKED. A local simulation PASS validates only its stated fixture hypothesis. CANDIDATE is a recommendation, never adoption permission. Promotion requires owner approval and production-specific verification; registry validation does not grant permissions. Record observable metrics only, preserve unknowns and rejection reasons.
